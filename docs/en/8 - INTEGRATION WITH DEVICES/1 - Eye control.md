If you use IGOOR with software such as TD Control by Tobii, you can set up a small trick to avoid many extra clicks.

**IMPORTANT: The IGOOR association is NOT affiliated with Tobii / Dynavox.**

In TD Control, by default, each time you want to interact with a button, TD Control asks you what type of action you want to perform (e.g. left click, right click, drag and drop, etc.)

However, **inside the IGOOR software everything is done with a left click**.

Here are a few tips:

To enable/disable continuous click in TD Control, it is the button to the right of the pause button (in the off-screen menu): it is a "+" symbol surrounded by 2 circular arrows.

By default, it allows you to repeat the left click, click-drag and held drag.

If nothing happens, the function may be disabled. In the menu, settings, go to Customize, Continuous Mode, choose Click on fixation.

Here, you can also add another button.

For information, there is also **a Repeat mode that allows you to:**

- **enable/disable left click only**

- **hover without clicking**

- **hide the gaze trace**
