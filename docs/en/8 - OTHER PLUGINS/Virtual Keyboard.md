## Activation

If you are not using IGOOR with an eye-tracking command (which works with its own virtual keyboard, e.g., Tobii's TD Control), nor a physical keyboard, you must manually activate the virtual keyboard. Go to:

Settings > Plugins > UI

And click the toggle switch on Virtual Keyboard to enable it:

![[virtual_keyboard.png]]

Restart IGOOR.
