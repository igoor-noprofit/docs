## Touch keyboard

If you are not using IGOOR with an eye-control device (which comes with its own virtual keyboard, e.g. Tobii's TD Control), nor a physical keyboard, the Windows TabTip.exe touch keyboard should appear on screen when you click on IGOOR's text fields.

If for some reason your touch keyboard does not appear, first check the Windows settings.

If you cannot get it to open, an extension lets you force the virtual keyboard to appear on the free-text input field.

## Forcing the virtual keyboard on

Go to:

*Settings > Extensions > UI*

And click the switch on Virtual Keyboard to enable it:

![[virtual_keyboard.png]]

Restart IGOOR.
