## Required Parameters

The first time you open IGOOR, the settings page opens automatically:

![Onboarding](../assets/igoor_onboarding.png)

You must save all required fields.

### Health Status

The health status is a crucial field because it systematically constrains the predictions provided by the AI based on the user's physical capabilities. If these capabilities change significantly, it is a good idea to update them even if IGOOR's memory might already contain this information.

<video src="https://igoor.org/wp-content/uploads/2025/09/IGOOR-mettre-a-jour-etat-de-sante.mp4" controls></video>

### Style

You can enter instructions in this field about the style of your sentences, which can profoundly alter the predictions generated by IGOOR. For example:

"She expresses itself with long sentences, full of philosophical quotes"

will produce very different predictions from:

"She prefers short, concise sentences with a very informal tone."
