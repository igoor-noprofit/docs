## Supported voice synthesis systems

IGOOR supports 3 TTS (Text-to-speech) options:

1. The **built-in Windows TTS** (TTSDEFAULT): this is the default voice when you install IGOOR;
2. **Elevenlabs**, one of the major players in the field of voice synthesis;
3. **Speechify** (an alternative to Elevenlabs).

<div style="background:red;color:#fff; padding: 10px">
Currently, IGOOR is experiencing an issue with Speechify, particularly in French. The bug originates from Speechify; it has been reported several times, but Speechify does not yet have a date for a fix.
In the meantime, we recommend Elevenlabs for the cloud. 
</div>

### Tips

- **If the IGOOR user is affected by ALS, the ARSLA association may have free licenses for Elevenlabs**. [Contact the ARSLA association](https://www.arsla.org/){target=blank} or [follow the Impact program process offered by Elevenlabs](https://elevenlabs.io/fr/blog/expanding-access-patients-and-clinicians-can-now-apply-directly-on-the-elevenlabs-website).
- If you have the option to clone the user's voice, we recommend doing so: **the person's original voice (or a more expressive Windows voice) helps maintain an emotional connection with the user.** 
- Only if you cannot clone the user's voice, or if you want a free voice, choose [[2 - Windows voice synthesis]]
