**IGOOR** **è un software di CAA gratuito, open-source e libero (licenza AGPLv3)**, **basato sull'intelligenza artificiale**, per offrire alle persone colpite da patologie che compromettono la comunicazione un mezzo per comunicare nel modo più fluido e naturale possibile.
**La sua interfaccia è compatibile anche con l'uso tramite comando oculaire.**

## Cos'è IGOOR 

- Un software **sperimentale** di comunicazione assistita dall'I.A.
- **Un'applicazione conversazionale dedicata alla comunicazione in presenza**, il più possibile in tempo reale

> [Per saperne di più sulla filosofia alla base del software IGOOR](https://igoor.org/app/){target=blank}

## Cosa NON è IGOOR

- Un software di puntamento oculare o un dispositivo di eye-tracking (ma IGOOR può funzionare con dispositivi di eye-tracking, se li utilizzate)
- Un sistema integrato per accedere ai vostri social network, alla messaggistica telefonica ecc. (IGOOR è comunque compatibile con software come Grid3)
