Per impostazione predefinita, IGOOR utilizza la voce di sintesi fornita da Windows.
Per configurarla, andate in :

*Parametri > Home > Sintesi vocale > Configura la voce di Windows*

![[../assets/accueil.png]]

Deselezionate la casella per utilizzare **sempre** la voce di Windows ; in caso contrario, sarà utilizzata solo in caso di malfunzionamento della voce clonata.

![[../assets/ttsdefault.png]]

**SUGGERIMENTO : Se clonate la vostra voce via cloud, mantenete la casella selezionata per utilizzare la voce di Windows in caso di problemi di rete.**

Scegliete la voce desiderata nel menu a tendina tra le voci disponibili, e salvate i parametri del plugin.
