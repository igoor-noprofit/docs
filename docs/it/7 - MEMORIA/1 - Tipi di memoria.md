
A partire dalla versione 1, puoi fornire molte informazioni a IGOOR fin dall'inizio, attraverso la [[2 - Registrazione della memoria biografica]].

IGOOR è dotato di tre tipi di memoria:

- [[3 - Memoria estratta dai tuoi documenti]] (manuale, statica)
- [[4 - Memoria a lungo termine]] (automatica, incrementale)
- [[5 - Memoria a breve termine]] (automatica, dinamica)

Queste memorie vengono utilizzate in modo diverso per personalizzare le previsioni del software:

- la prima è fornita da te;
- le altre due vengono aggiunte automaticamente dall'IA in base alle tue conversazioni attraverso il software IGOOR.
