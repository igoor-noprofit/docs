Si vous avez déjà terminé la [[2 - Configuration rapide]], vous pouvez passer à explorer la page Accueil.

![[../assets/accueil.png]]

Quand vous cliquez sur le bouton paramètres (en haut à droite), l'onglet *Accueil* permet d'accéder rapidement à la configuration de plusieurs extensions fondamentales : 

-  [[2 - Enregistrement de la mémoire biographique]]
- [[2 - Ajouter des interlocuteurs]]
- [[3 - Besoins quotidiens]]
- Les différentes extensions de synthèse vocale (cf. [[1 - Choisir votre système de synthèse vocale TTS]])
- [[5 - Boutons rapides]]
- [[3 - Mémoire extraite depuis vos documents]]
- d'autres extensions, une fois activées.

Vous pouvez également accéder à cette documentation, ou nous donner votre avis à travers un formulaire en ligne (🙏🏼 pour votre retour).
