## Avantages
**Cloner sa voix a des avantages évidents pour l'utilisateur et pour son entourage : la voix contribue à garder le lien émotionnel avec la personne qui l'a perdue.**

Si l'utilisateur a la possibilité d'utiliser sa voix, il est possible de réaliser des enregistrements pour la cloner. Si ce n'est pas le cas, mais que vous disposez d'échantillons de la voix de l'utilisateur, vous pouvez la cloner à partir de ces échantillons. Dans ce dernier cas, cependant, il va falloir couper les parties qui ne correspondent pas à la voix de l'utilisateur. 

Dans les deux cas, il est possible de créer un **clone de voix instantané** (qui demande à peu près **1 minute d'enregistrement** de la voix de l'utilisateur) ou **professionnel** (celui-ci peut demander jusqu'à **trois heures d'enregistrements**).

Consultez cette page sur le site IGOOR pour des conseils sur l'enregistrement de votre voix et si vous souhaitez etre accompagné sur l'enregistrement de votre voix :

[Conseils pour l'enregistrement vocal](https://igoor.org/enregistreur-vocal/){target=blank}

**Cet outil est utilisé également pour la création d'un document avec des informations sur vous et vos proches qui nourrissent l'IA d'IGOOR** à travers différents [[1 - Types de mémoire]].

## Utiliser une voix de synthèse dans le cloud

**IMPORTANT : Nous vous conseillons de garder activée la voix de synthèse Windows en cas de problèmes réseau.**

Pour ce faire, dans les paramètres de l'extension ci-dessus, gardez la case cochée. 

Ensuite, activez l'extension correspondante à votre abonnement (Elevenlabs ou Speechify), depuis :

Paramètres > Accueil > Extensions > TTS

**NOTE**: **Si vous activez plus d'un fournisseur dans le cloud, votre voix sera doublée.**

**Vous devez redémarrer IGOOR quand vous activez / désactivez une nouvelle extension.**

Vous allez devoir ensuite **renseigner votre clé API** pour l'accès au service. Par exemple, pour Speechify :

![[../assets/speechify.png]]

**Une fois la clé API renseignée, la liste des voix disponibles se remplira automatiquement.**
