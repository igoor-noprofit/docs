
À partir de la version 1, vous pouvez donner plein d'informations à IGOOR dès le départ, à travers l'[[2 - Enregistrement de la mémoire biographique]].

IGOOR est doté de trois types de mémoire :

- [[3 - Mémoire extraite depuis vos documents]] (manuelle, statique)
- [[4 - Mémoire de long terme]] (automatique, incrémentale)
- [[5 - Mémoire de court terme]] (automatique, dynamique)

Ces mémoires sont utilisées de façon différente pour personnaliser les prédictions du logiciel :

- la première est fournie par vous ;
- les deux autres sont automatiquement ajoutées par l'IA en fonction de vos conversations à travers le logiciel IGOOR.
