Par défaut, IGOOR utilise la voix de synthèse fournie par Windows.
Pour la configurer, allez dans :

*Paramètres > Accueil > Synthèse vocale > Configurer la voix de Windows*

![[../assets/accueil.png]]

Décochez la case pour utiliser **toujours** la voix de Windows ; autrement, elle ne sera utilisée qu'en cas de malfonctionnement de la voix clonée.

![[../assets/ttsdefault.png]]

**ASTUCE : Si vous clonez votre voix via le cloud, gardez la case cochée pour utiliser la voix de Windows en cas de problèmes réseau.**

Choisissez la voix que vous souhaitez dans le menu déroulant parmi les voix disponibles, et enregistrez les paramètres du plugin.
