## Activation

Si on n'utilise pas IGOOR avec une commande oculaire (qui fonctionne avec son clavier virtuel, par ex. TD Control de Tobii), ni un clavier physique, il faut activer manuellement le clavier virtuel. Allez dans :

Paramètres > Extensions >  UI 

Et cliquez le bouton du switch sur Virtual Keyboard pour l'activer :

![[virtual_keyboard.png]]

Redémarrez IGOOR.
