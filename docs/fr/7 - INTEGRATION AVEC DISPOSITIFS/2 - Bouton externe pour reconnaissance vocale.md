N'importe quel bouton externe compatible avec votre dispositif peut être utilisé pour déclencher la reconnaissance vocale.
Le bouton externe déclenche la transcription vocale ; quand vous le cliquez à nouveau, il la termine.
 
![[../assets/asr_button.png]]
Votre bouton doit envoyer un raccourci clavier à IGOOR.
**Le raccourci clavier par défaut est CTRL+K**, mais vous pouvez le modifier à tout moment dans : 

Paramètres > Accueil > Reconnaissance vocale > Configurer la reconnaissance vocale 

Cliquez sur le champ de texte :

![[../assets/keyboard_combination.png]]

Et cliquez sur votre bouton externe. La combinaison de touches envoyées par votre bouton externe apparaitra dans le champ de texte.
Sauvegardez les paramètres.

**NOTE : D'autres modalités de déclenchement de la reconnaissance vocale seront disponibles dans la v1 du logiciel.**
