## Clavier tactile

Si on n'utilise pas IGOOR avec une commande oculaire (qui fonctionne avec son clavier virtuel, par ex. TD Control de Tobii), ni un clavier physique, le clavier tactile TabTip.exe de Windows devrait s'afficher à l'écran quand on clique sur les champs de texte d'IGOOR.

Si pour quelques raisons votre clavier tactile ne s'affiche pas, regardez d'abord dans les paramètres de Windows.

Si vous n'arrivez pas à le déclencher, une extension permet de forcer l'affichage du clavier virtuel sur le champ de saisie libre automatique.

## Activation forcée du clavier virtuel

Allez dans :

*Paramètres > Extensions > UI* 

Et cliquez le bouton du switch sur Virtual Keyboard pour l'activer :

![[virtual_keyboard.png]]

Redémarrez IGOOR.
